# 第二種電気工事士 CBT模擬試験Webアプリ (denkou2-cbt)

第二種電気工事士の試験対策が行える、CBT（Computer Based Testing）方式対応のオープンソース模擬試験Webアプリケーションです。

## 🌟 主な特徴

- ⚡ **本番形式の出題**: 実際の過去問をベースにした全50問・120分タイマー・30問合格ライン設定
- 📱 **PWA対応**: iOS / Android スマートフォンのホーム画面に追加してアプリとして利用可能
- 🌓 **ダーク / ライトモード自動・手動切替**: 目の負担を軽減するテーマ設定機能
- 📊 **詳細な結果分析**: 正解（緑）・不正解（赤）の視覚的な色分けと、全問題への丁寧な解説表示
- 🚩 **後で見返す標識機能**: 解答に迷った問題にフラグを立てて後から見直し可能
- shadow/アニメーションを取り入れたレスポンシブデザイン

## 🛠️ 使用技術 (Tech Stack)

- **Frontend**: HTML5, JavaScript (ES6+)
- **Styling**: Tailwind CSS (CDN)
- **Icons**: Lucide Icons
- **Deployment**: Cloudflare Pages / Cloudflare Workers
- **PWA**: Web App Manifest

## 🚀 使い方

1. 「試験を開始する」ボタンを押して模擬試験を開始します。
2. 50問の四肢択一（イ・ロ・ハ・ニ）問題に解答します。
3. 必要に応じて「後で見返す」ボタンでフラグを立て、パレットから問題へ移動できます。
4. 解答終了後、「終了・採点」を押すと自動採点と詳細解説が表示されます。
